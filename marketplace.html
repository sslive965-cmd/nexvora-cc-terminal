01 — HOW TO BUY

  1. Marketplace me RUPAY, VISA, MASTERCARD ya AMEX category select karein.
  2. Available product ko carefully review karein.
  3. Product ke BUY NOW button par tap karein.
  4. Order/payment page par jo required information ho, use carefully enter karein.
  5. Order submit hone ke baad milne wala Order ID save karke rakhein.
⚠ Product details ko order submit karne se pehle carefully check karein.

02 — HOW TO TRACK ORDER

  1. Top-right me TRACK ORDER tap karein.
  2. Track page par apna Order ID enter karein.
  3. Agar email verification required ho, order wali email enter karein.
  4. Submit karne ke baad current order status check karein.
📦 Order ID ko safe rakhein. Ye tracking ke liye important hai.

03 — SUPPORT

Website, order ya tracking me technical problem aaye to top-right ka SUPPORT button use karein.

💬 Support ko contact karte waqt Order ID aur problem ka short description dena helpful rahega.

04 — ORDER & VERIFICATION

  • Order submit hone ke baad status verification ke liye pending ho sakta hai.
  • Verification complete hone se pehle order ko completed/verified na samjhein.
  • Incorrect information se processing delay ho sakta hai.

05 — SECURITY RULES

  • Password, OTP ya account login details share na karein.
  • Full payment-card number, CVV, PIN ya OTP kisi person ko chat me share na karein.
  • Sirf official website ke available buttons/links ka use karein.
  • Unknown ya suspicious links par tap na karein.

06 — GENERAL RULES

  • Product availability change ho sakti hai.
  • Final order status authorized verification process ke according hota hai.
  • Ek order ke liye duplicate submissions avoid karein.
  • Problem hone par Order ID ke saath Support se contact karein.
